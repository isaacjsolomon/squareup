How This Website Was Made

DoWeo started as an idea to make it easier for friends to track and settle shared expenses. Here’s how the website came together.

  1. 1
    💡

    The Idea

    A simpler way to keep track of shared costs, see who owes whom, and automatically calculate balances.

    The beginning
  2. 2
    💻

    Built with Netlify

    The first working version of DoWeo was created with Netlify’s AI website builder.

    First version
  3. 3
    🗄️

    Added Supabase

    Supabase brought user accounts, profiles, shared trackers, expenses, and the database behind the app.

    The foundation
  4. 4
    ☁️

    Moved to Cloudflare Pages

    The website moved to Cloudflare Pages, with code managed through GitHub and server-side features connected to Supabase.

    New home
  5. 5
    👥

    Added More Features

    Expense splitting, Smart Settle-Up, group chat, notifications, friends, receipt tools, and tracker customization made DoWeo more useful.

    Growing
  6. 6

    Constantly Improving

    DoWeo continues to evolve through testing, fixing bugs, and ideas from the people who use it.

Add DoWeo to Home Screen

Safari needs a few taps to install DoWeo as an app.

  1. Tap Safari’s Share button. If it is inside the page menu, open that menu and tap Share.
  2. Scroll down and select Add to Home Screen.
  3. Keep Open as Web App turned on, if shown, then tap Add.

Apple requires these steps; websites cannot install themselves automatically.
